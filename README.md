# Odiómetro

Observatorio de violencia digital contra candidatas en Ecuador.

## Dónde está publicado

**https://breakervibe.github.io/odiometro/** — GitHub Pages, desde la rama
`main` de este repositorio. Cada `git push` redespliega el sitio.

Este repositorio es **público** y contiene únicamente el sitio web: ningún
dato crudo ni credencial vive aquí.

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | Portada |
| `odiometro.html` | El observatorio |
| `metodologia.html` | Cómo se construye la medición |
| `quienes-somos.html` | Equipo |
| `tablero/` | Tablero de datos |
| `css/`, `js/`, `img/`, `fonts/` | Recursos del sitio |

El análisis que alimenta este sitio vive en el proyecto `odiometro-analisis`,
que es privado.
